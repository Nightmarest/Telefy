## Установка

Основной рассчёт - на пользователей Windows. Файл .exe вы сможете найти в релизах. 

Однако, ничего не мешает вам запустить скрипт на чистом Python. 

В каком-то смысле, это даже плюс - вы сможете дать возможность скрипту работать бесперебойно, установив подобный скрипт на сервер посредством Python.

```
$ pip install -r requirements.txt

$ python3 Startup.py
```

## Запуск

При первом запуске создаётся файл `config.ini` с настройками. 

| Группа     | Описание                                  |
|------------|-------------------------------------------|
| `SP_AUTH`  | Содержит в себе настройки для API-клиента |
| `TG_CONF`  | Настройки для Telegram.                   |
| `GENERAL`  | Содержит в себе общие настройки.          |


### Фоновый режим

Для того, чтобы скрыть приложение в фоновый режим, вам необходимо скрыть приложение через Tray:

![Tray](assets/Tray.png)

### Настройки Telegram

Текст обновляется и создаётся в сообщенях чата.

Предполагается использование вместе с привязкой канала к профилю: таким образом, текст будет виден при просмотре профиля.

| Параметр    | Описание                                    |
|-------------|---------------------------------------------|
| `bottoken`  | Токен бота [отсюда](https://t.me/BotFather) |
| `channelid` | ID канала (начинается с -100)               |

### Настройки Spotify

Создать приложение можно [тут](https://developer.spotify.com/dashboard)

Обратите внимание, что при первом запуске, скрипт потребует от вас ввести ссылку, на которую вас перевели после входа в приложение через Spotify. Эта ссылка будет в строке URL.

![Screenshot](assets/LinkExample.png)

Для того, чтобы вы смогли без проблем получить токен, вам будет необходимо установить в приложении Spotify, а также в конфиге любой __недействительный__ URL. К примеру, https://derise.org/

| Параметр        | Описание                                              |
|-----------------|-------------------------------------------------------|
| `client_id`     | ID приложения (Можно получить из настроек приложения) |
| `client_secret` | Токен приложения (Также можно получить в настройках)  |
| `callback_url`  | URL, который вы ввели в настройках приложения.        |

### Общие настройки

| Параметр          | Описание                                  |
|-------------------|-------------------------------------------|
| `NotPlaying`      | Сообщение, когда ничего не играет         |
| `RefreshInterval` | Интервал обновления времени прослушивания |

## Режим сайта без Telegram

Для передачи текущего трека на личный сайт можно запустить Telefy отдельно от Telegram. Этот режим работает на macOS, Linux и Windows; он не импортирует Telegram, системный трей или Windows API.

```sh
python3 -m venv .venv
# macOS / Linux:
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements-website.txt
cp config.example.ini config.ini
python -m src.Connect
python -m src --mode website
```

В `config.ini` укажите Spotify `CLIENT_ID`, при необходимости `CLIENT_SECRET`, адрес сайта в `[WEBSITE] Endpoint` и согласованный с сервером `Token`. Если секрет Spotify пуст, используется PKCE. В настройках приложения Spotify должен быть разрешён Redirect URI `http://127.0.0.1:8888/callback`. `src.Connect` печатает ссылку для одноразового входа; её нужно открыть в браузере. Пароли и токены не отправляются посетителям сайта.

`[GENERAL] Mode = website` выбирает этот режим и без аргумента `--mode`. Старый Telegram-режим можно явно выбрать через `--mode telegram` в его прежнем Windows-окружении. Telegram-настройки для режима сайта не требуются.

Сайт получает авторизованный `POST` с идентификатором Spotify, названием, исполнителями, обложкой, длительностью, точной позицией в миллисекундах, состоянием воспроизведения и временем наблюдения. Обновления идут с интервалом `RefreshInterval` (1–10 секунд). Локальные треки, подкасты и приватная сессия не публикуются. При штатной остановке отправляется событие остановки; при потере связи сайт должен самостоятельно скрыть устаревшее состояние. Для внешнего адреса требуется HTTPS, для локального разрешён HTTP.

Spotify-токен сохраняется в `.local/spotify-token.json`; этот каталог и `config.ini` исключены из Git. Проверки без подключённых сервисов: `python -m unittest discover -s tests -v`.
